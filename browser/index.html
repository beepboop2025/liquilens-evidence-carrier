    What this proves

    A full carrier and a reference are different instruments.

    F

    Full carrier

    The verifier parses numeric lexemes without losing integer precision, builds the liquilens-hash-tree-v1 tree, recomputes SHA-256, and binds the carrier ID to that digest.

    R

    Redacted reference

    The verifier enforces the reference schema, confirms the payload is absent, and binds the preserved carrier ID to the declared full-carrier hash. It never pretends to re-hash undisclosed content.

    Ø

    No authority upgrade

    Both contracts must keep execution, recommendation, and credit-rating authority false. Structural verification is not financial advice or a market-data entitlement.
