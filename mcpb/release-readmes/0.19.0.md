# LiquiLens Evidence Carrier 0.19.0

This immutable-per-version bundle README describes the bytes prepared for the
v0.19.0 MCPB candidate. Its presence in a source tree or locally built bundle
is not publication proof. Until a successful protected-main preflight and
controlled signed-tag workflow publish, attest, and register the exact bytes,
v0.18.0 remains the production pin.

Version 0.19.0 preserves every Trade Safety v1 schema byte and adds a committed
adversarial raw-byte corpus plus a dependency-free TypeScript-compatible Node
verifier and authenticated paper-only order guard. The corpus covers pass,
limit, hold, unavailable, numeric lexemes, oversized integers, duplicate keys,
invalid UTF-8, tamper, HMAC failure, expiry, replay, and unconditional live
rejection, including future request/receipt clocks and independent account,
policy, issuer, and key bindings. The MCP server remains offline, secretless,
and read-only.

## Offline tools and assets

The stdio server exposes the same four local-file verification/projection tools
as v0.18.0 and now lists the conformance corpus as an MCP resource. The bundle
also carries `integrations/typescript`, including ESM runtime code and TypeScript
declarations. It makes no network request and exposes no order, broker,
credential, signing-key, recommendation, rating, or execution tool.

The public corpus HMAC key is a deterministic fixture and is never a production
secret. The TypeScript gateway owns its clock, requires a caller-supplied
tenant-local HMAC key and exact operator binding, atomically claims each receipt
through a caller-supplied consumer, and invokes only a paper submit callback.
The bundled in-memory consumer is for tests and local demos, not distributed
durability. The separately packaged HTTP gateway is not embedded in or started
by this offline MCPB.

## Publication verification

Before treating a downloaded bundle as v0.19.0, verify the signed annotated tag,
the exact allowlisted candidate commit and protected-main ancestry, successful
release workflow and provenance attestations, `SHA256SUMS`, and the active
official MCP Registry record. No such publication receipt is asserted by this
candidate README.
