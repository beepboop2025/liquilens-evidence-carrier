# LiquiLens Evidence Carrier 0.20.0

This immutable-per-version bundle README describes the bytes prepared for the
v0.20.0 MCPB candidate. Its presence in a source tree or locally built bundle
is not publication proof. The signed and published v0.19.0 release remains the
production pin until the protected release workflow accepts this candidate.

Version 0.20.0 adds two offline MCP resources: the Seiche research-network
response schema and the connected product routing map. They describe how an
agent can discover Palimpsest's source registry, Seiche funding context,
LiquiLens institution evidence, Undertow exit liquidity, NarcoScope datasets,
and Market Brief coverage. Reading these resources makes no network request.

The four existing local-file verification and projection tools retain their
meaning, as do every existing Trade Safety v1 schema byte and the adversarial
conformance corpus. The server remains offline, secretless and read-only.
The separately packaged HTTP gateway is not embedded in or started by this offline MCPB.
Discovery metadata does not establish evidence availability, source freshness,
redistribution rights, causal attribution, validated backtests, or financial
authority. Those decisions remain with each source's native evidence contract.

Before treating a downloaded bundle as v0.20.0, verify its signed annotated tag,
exact accepted source commit, protected-main ancestry, release workflow,
provenance attestations, SHA256SUMS, and active official MCP Registry record.
No such publication receipt is asserted by this candidate README.
